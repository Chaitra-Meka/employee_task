# Employee Task Tracker

A full-stack Employee Task Tracker application.

## Technologies

- React
- TypeScript
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

## Features

### Employee Management
- Add employees
- View employees
- Delete employees
- Search employees by name

### Task Management
- Create tasks
- Assign tasks to employees
- View assigned employee names
- Update task status
- Delete tasks
- Filter tasks by status

### Dashboard
- Total employees
- Total tasks
- Completed tasks
- Pending tasks

## Backend Setup

1. Navigate to backend.

2. Create virtual environment.

3. Activate environment.

4. Install dependencies.

5. Configure PostgreSQL connection in .env.

6. Run:

uvicorn app.main:app --reload

## Frontend Setup

1. Navigate to frontend.

2. Install dependencies:

npm install

3. Configure frontend .env.

4. Start application:

npm run dev
